보건의료 AI 수업 과제용으로, 요양기관 결원·교대 공백 예측 AI ‘CareGap’의 아주 간단한 웹 프로토타입을 만들어줘.

조건:
- 외부 API, 데이터베이스, 로그인 기능은 사용하지 마.
- 가상의 요양기관 데이터를 코드 안에 직접 넣어줘.

화면 구성은 딱 3개로만 해줘:
1. 상단: 기관명 ‘행복요양병원’, 조회 기간 ‘향후 2주’ 표시
2. 중간: 부서별 결원 위험 카드 3개
   - 야간간호팀: 위험 높음 / 재활치료팀: 위험 보통 / 행정팀: 위험 낮음
   각 카드에는 위험도 색상(빨강/노랑/초록), 예상 공백 시간대, 핵심 원인 한 줄을 넣어줘.
3. 하단: 관리자 대응 옵션 3개를 버튼으로 보여줘
   - 대체 인력 요청 / 교대 조정 / 우선 돌봄 업무 재배치
   버튼을 누르면 “관리자 검토 후 최종 승인 필요합니다”라는 안내 문구가 뜨게 해줘.

중요한 원칙:
- AI가 개인별 근무기록을 보여주거나, 특정 직원의 해고·교체를 제안하지 마.
- 모든 데이터는 부서·교대 단위의 익명화된 집계 데이터로 보여줘.
- 화면 하단에 “본 데모는 가상 데이터를 사용한 교육용 프로토타입입니다.”라고 표시해줘.
- 디자인은 깔끔하고 실무자가 바로 이해할 수 있게, 설명 문구는 짧게 써줘.
